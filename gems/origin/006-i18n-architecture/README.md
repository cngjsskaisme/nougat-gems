# 💎 Origin 006 — i18n Architecture

A Gem for treating Locale as a cross-layer contract spanning **Routing, CMS, SEO, Static Data, and AI Response Language**, rather than limiting internationalization to UI string translation.

Only reusable architecture remains from the source implementation; project names, personal domains, absolute local paths, real API endpoints, and personal SEO data have been removed.
