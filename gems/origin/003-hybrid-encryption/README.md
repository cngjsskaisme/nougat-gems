# 💎 Origin 003 — Hybrid Encryption

A Hybrid Encryption Gem that encrypts application payloads between Browser and Backend with a per-request symmetric key, then wraps that symmetric key with the server's public key for transport.

> This Gem does not replace HTTPS. It is also not a complete End-to-End Encryption model because the Backend ultimately processes plaintext.
