# 💎 Origin 003 — Hybrid Encryption

브라우저와 Backend 사이의 애플리케이션 Payload를 요청별 대칭키로 암호화하고, 대칭키를 서버 공개키로 감싸 전달하는 Hybrid Encryption Gem입니다.

> 이 Gem은 HTTPS를 대체하지 않습니다. Backend가 평문을 처리하므로 완전한 End-to-End Encryption 모델도 아닙니다.
