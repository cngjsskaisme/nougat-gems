# 💎 Origin 007 — Guest HMAC Authentication

로그인 계정이 없는 서비스에서 짧은 Guest Session과 HMAC Request Signature를 사용해 API Abuse, Replay, Request Tampering을 줄이는 Gem입니다.

> Guest Client Authentication은 사용자 신원을 증명하는 User Authentication이 아닙니다. Client가 Secret을 보유하므로 XSS나 탈취된 실행 환경까지 보호하는 모델도 아닙니다.
