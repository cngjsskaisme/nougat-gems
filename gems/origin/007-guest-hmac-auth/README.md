# 💎 Origin 007 — Guest HMAC Authentication

A Gem for reducing API abuse, replay attacks, and request tampering in services without user accounts by combining short-lived Guest Sessions with HMAC Request Signatures.

> Guest Client Authentication is not User Authentication. Because the client holds a Secret, this model also does not protect against XSS or a compromised client execution environment.
