# 💎 Origin 005 — Mobile Native FAB Avoidance

A Gem for avoiding overlap between browser-native floating controls and fixed bottom web UI by **temporarily repositioning the web UI** instead of attempting to hide browser-owned controls.

The current design uses cases such as Samsung Internet's native scroll-to-top control as its primary context.
