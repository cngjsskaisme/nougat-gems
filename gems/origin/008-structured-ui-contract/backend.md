# Structured UI Contract — Backend

## Intent

The LLM must not generate HTML, Script, Component Import Paths, functions, or arbitrary API Endpoints. It may respond only within a predefined Component, Props, and Action Contract.

## Response Contract

```text
version
component
props
actions
metadata
```

Metadata such as requestId, model/provider, and contractVersion is generated by the Backend, not by the LLM.

## Allowlist

The Backend manages the following as explicit allowlists:

- Components
- Props Schema per Component
- Actions
- Payload Schema per Action
- allowed Component ↔ Action relationships

An Action is rejected if it is not allowed for the selected Component, even when it is individually schema-valid.

## Workflow Boundary

The LLM may **propose** an external operation, but it never executes the operation itself.

```text
LLM Response
  ↓ proposes action
Frontend explicit user action
  ↓
Execution API
  ↓ validate again
External side effect
```

Success UI should be created from the real Side Effect result by trusted Backend/Frontend logic. An LLM merely claiming success is not sufficient.

## Runtime Validation

Immediately after receiving LLM Output, validate:

- JSON parse
- contract version
- component enum
- props schema
- action enum / payload
- component-action policy
- response size / string length
- state/workflow policy where applicable

Do not forward an invalid raw model response to the Client. Convert it into a safe Fallback Contract.

## Prompt Boundary

Separate System Rules, UI Contract, Component/Action Definitions, Runtime State, User Conversation, and Output Schema. User input must not be able to override the contract by requesting schema bypass, unknown Components/Actions, or disclosure of the System Prompt.

## Security

- prohibit `eval`, Function Constructor, and dynamic imports from model output
- prohibit arbitrary endpoints, scripts, and HTML
- represent external links through registered IDs plus an allowlist
- exclude private input/prompt/payload contents from default logs
