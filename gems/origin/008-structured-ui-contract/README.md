# 💎 Origin 008 — Structured UI Contract

A **framework-independent Structured UI Contract** Gem that restricts an LLM to a known set of Components and Actions, then connects those declarations to real UI and domain Actions through a Frontend Registry and State Machine.

Origin 002 uses the concrete `json-render` runtime. This Gem focuses on the boundaries needed when operating a smaller custom contract directly.
