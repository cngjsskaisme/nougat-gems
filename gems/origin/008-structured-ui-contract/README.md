# 💎 Origin 008 — Structured UI Contract

LLM이 제한된 Component와 Action만 선택하도록 하고, Frontend Registry와 State Machine을 통해 실제 UI와 업무 Action을 연결하는 **Framework-independent Structured UI Contract** Gem입니다.

Origin 002가 `json-render`라는 구체적인 Runtime을 사용하는 접근이라면, 이 Gem은 더 작은 Custom Contract를 직접 운영할 때 필요한 경계를 정리합니다.
