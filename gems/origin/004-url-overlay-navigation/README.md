# 💎 Origin 004 — URL Overlay Navigation

A Gem for connecting user-visible UI states—not only pages, but also overlays, dialogs, sheets, and multi-step flows—to URLs and Browser History.

The core idea is to **separate Presentation from Navigation Policy** and keep the URL contract simple with three fields: `action / payload / meta`.
