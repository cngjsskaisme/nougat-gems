# 🗺️ Terminology

| Game Concept | Gem Programming | Engineering Meaning |
|---|---|---|
| Item / Gear | Project / System | 완성된 구현 |
| Mining | Design Extraction | 기존 구현에서 재사용 후보 판단 추출 |
| Raw Gem | Raw Design | 프로젝트 흔적이 남아 있는 초기 추출물 |
| Refining | Distillation | 프로젝트 의존성 제거와 일반화 |
| Gem | Reusable Design Asset | Agent가 다시 구현할 수 있는 설계 단위 |
| Stash | Gem Repository | Gem 저장소 |
| Socket | Design Extension Point | 새 시스템에서 Gem이 담당할 책임 영역 |
| Socketing | Contextual Composition | 현재 프로젝트 Context에 Gem 적용 |
| Crafting | Adapter Synthesis | Gem 사이 Contract Gap을 연결하는 설계 생성 |
| Mixed Gem | Integration Knowledge | 조합 과정에서 새로 생긴 지식 |
| Validation | Acceptance Boundary | 생성 결과가 지켜야 할 규칙 검증 |
| Upgrade | Gem Revision | 검증 결과를 반영한 Gem 개선 |
