# 🗺️ Terminology

| Game Concept | Gem Programming | Engineering Meaning |
|---|---|---|
| Item / Gear | Project / System | A complete implementation |
| Mining | Design Extraction | Extract reusable decisions from an existing implementation |
| Raw Gem | Raw Design | An initial extraction that still contains project-specific traces |
| Refining | Distillation | Remove project dependencies and generalize the design |
| Gem | Reusable Design Asset | A design unit an agent can reimplement |
| Stash | Gem Repository | A repository of Gems |
| Socket | Design Extension Point | The responsibility a Gem fills in a new system |
| Socketing | Contextual Composition | Apply a Gem to the current project context |
| Crafting | Adapter Synthesis | Design the connection across a contract gap between Gems |
| Mixed Gem | Integration Knowledge | New knowledge discovered while composing Gems |
| Validation | Acceptance Boundary | Verify the rules generated results must satisfy |
| Upgrade | Gem Revision | Improve a Gem using validation and production feedback |
